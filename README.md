# Spotify-Style Music Data Pipeline

## Project Overview

This project is an end-to-end Data Engineering project that simulates a music streaming data platform.

The project demonstrates how raw music streaming data can be cleaned, transformed, analyzed, stored, and visualized using Python, Pandas, SQL, and SQLite.

This project uses synthetic data and is not affiliated with Spotify.

## Business Problem

A music streaming platform generates large amounts of data from users, songs, artists, genres, countries, devices, and listening activity.

The goal of this project is to transform raw streaming data into meaningful business insights.
